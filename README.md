# Hilary & Elliott's Wedding App

An installable wedding website — a guest directory ("face book"), schedule,
local guide, registry, and more. It's a static site generated by `build.py` and
hosted on Vercel (pushing to `main` publishes it automatically).

**New here? Start with [GETTING-STARTED.md](GETTING-STARTED.md).** It walks you —
in plain English, no coding needed — through installing the tools, getting the
code onto your Mac, and editing the site by simply asking Claude Code.

For how the project is built and the rules to follow (what it does and doesn't
include, how the form fields map, the never-fabricate rule), see
[CLAUDE.md](CLAUDE.md) — Claude Code reads that automatically when you open it
here.
